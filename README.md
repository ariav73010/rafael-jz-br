# Rafael · JZ

Página pessoal estática em português, feita com HTML, CSS e JavaScript. As imagens locais ficam em `assets/`.

## Publicar com GitHub Pages

1. Crie um repositório no GitHub e envie o conteúdo desta pasta para a raiz dele.
2. No repositório, abra **Settings → Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**, selecione `main` e a pasta `/ (root)`, e salve.
4. O GitHub Pages mostrará o endereço do site nessa mesma tela quando a publicação terminar.

Também dá para abrir `index.html` diretamente no navegador para conferir localmente. A fonte usa Google Fonts quando há conexão; o restante do site e as imagens são arquivos locais.
